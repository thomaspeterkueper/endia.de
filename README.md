# Endia

Website zur Buchreihe Endia — eine Young-Adult-Trilogie (Digital Rebellion). Das Spiel innerhalb des Buches war der Ausgangspunkt für den Aufbau des gesamten KUEPER-Ökosystems.

## Rolle im Ökosystem

Endia ist Teil des KUEPER-Ökosystems (Ökosystem-Code `ENDIA`). Details:
[`decisions/ECO-ARC-0016-2026-DE.md`](https://github.com/thomaspeterkueper/kueper-ecosystem/blob/main/decisions/ECO-ARC-0016-2026-DE.md)
im Repository `kueper-ecosystem`.

`external-tasks/open/`. Format:
